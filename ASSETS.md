# Asset manifest
All visuals are procedural. Nothing local is required.
- Fonts: Barlow Condensed and Barlow from Google Fonts (index.html).
- Optional: `ASSETS.spikeModel` (GLB URL) and `ASSETS.agentPortraits[id]` (image URL) in `src/data/config.js`. Only use assets you have rights to.
- Agent art: transparent WebP layers, back to front, about 3:4 ratio, under 300 KB each. See the example in `src/data/config.js`.
